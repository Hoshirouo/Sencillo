# Sencillo · Sistema web de gestión financiera para el minimarket Nicol

Prototipo funcional del proyecto final del curso **Interacción Humano Computador** (Universidad Privada del Norte, 2026-2).

**Sencillo** ayuda a la dueña y a la cajera de un minimarket de barrio a registrar ventas y gastos, cuadrar la caja y saber con anticipación si el dinero alcanzará para los pagos del mes. Su asistente, **Sencillito**, responde preguntas rápidas sin tener que navegar por el sistema.

## Probar el prototipo

- **En línea:** https://hoshirouo.github.io/sencillo/ (requiere activar GitHub Pages, ver abajo)
- **En tu computadora:** descarga `index.html` y ábrelo con Chrome o Edge.

Usuarios de prueba (contraseña `demo1234`):
- **Edith (dueña):** ve todas las secciones.
- **Cajera:** solo registra ventas, pedidos de apps y el cierre de caja.

Los datos son de ejemplo y se reinician al recargar la página.

## Funciones principales

| Función | Qué hace |
|---|---|
| Inicio | Ganancia del día, acciones rápidas y avisos importantes |
| Registrar | Ventas (efectivo, Yape, Plin, tarjeta), gastos y pedidos de apps de reparto con comisión automática |
| Caja | Cuadre de caja por medio de pago con aviso si la diferencia supera S/ 5 |
| Agenda de pagos | Proyección de los próximos 30 días: avisa qué pago no alcanzaría y cuánto juntar al día |
| Indicadores | 9 KPI con cálculo, periodicidad, actualización, herramienta, meta y decisión; exportación CSV para Power BI |
| Reportes | Ingresos, gastos y ganancia por periodo |
| Sencillito | Asistente de preguntas rápidas (texto o voz) |

## Accesibilidad

Diseñado según las WCAG 2.2 (nivel AA): alto contraste, letra ampliable, Modo simple, uso completo con teclado (atajos Alt+V, Alt+G, Alt+P, Alt+A), compatibilidad con lectores de pantalla, lectura en voz alta y dictado por voz (Chrome o Edge).

## Tecnologías

HTML5, CSS3, JavaScript, Bootstrap 5.3, Web Speech API e Intl (formato es-PE).
